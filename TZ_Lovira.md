## 1. Описание продукта

Lovira — приложение для общения с AI-компаньоном: пользователь выбирает готовую девушку или создаёт свою, ведёт с ней переписку, обменивается голосовыми, получает фото и короткие видео. Персонажи — **фотореалистичные**, выглядят как реальные люди (не аниме, не 3D), визуально стиль и подача как у candy.ai: тёмная тема, розовые акценты, крупные фото-карточки.

Цели:
- снизить чувство одиночества, дать безопасное пространство для разговора, флирта и ролевых игр;
- ответы «как живой человек», память о деталях пользователя;
- мультимодальность: текст, голос, фото, видео;
- приватность переписки;
- монетизация через подписку (Premium) и внутреннюю валюту.

### 1.1 Боли пользователя (из Notion)
- шаблонные «роботичные» ответы;
- однообразие персонажей;
- только текст, нет голоса и визуала;
- жёсткие бесплатные версии;
- страх за приватность.

## 3. Персонажи: фотореализм

### 3.1 Требования к визуалу
- Все персонажи выглядят как реальные люди: «фото со смартфона / фотосессия», натуральная кожа, реалистичный свет. Никакого аниме, мультяшности, 3D, «пластиковой» кожи.
- Персонаж должен быть **узнаваемо одним и тем же человеком** на всех фото (консистентность лица).
- Все персонажи — совершеннолетние (в промптах возраст всегда 21+, явное указание `adult woman`).
- Не использовать имена и внешность знаменитостей/реальных конкретных людей; ввод имён знаменитостей в кастомных промптах фильтруется.
- Контент — романтический/флирт, без откровенной наготы (требование App Store 1.1.4); `enable_safety_checker: true` всегда.

### 3.2 Предустановленные персонажи
- Минимум **8** персонажей на релиз (в Notion минимум 4+; 8 нужно для наполненной главной).
- У каждого: имя, возраст, страна/город, короткое био (2–3 предложения), 3 черты характера (например «заботливая», «остроумная», «авантюрная»), интересы, голос (`voice_id`), стартовое приветствие, системный промпт, обложка 3:4, аватар 1:1, галерея 8–12 фото + 1–2 видео.
- Разнообразие внешности: разные этничности, цвет волос, стиль (girl-next-door, офис, спорт, богема, и т.д.).
- Ассеты пресетов **генерируются заранее** (через этот же API, скриптом или вручную), проходят ручной отбор и **кладутся в бандл / CDN**, чтобы не тратить генерации и не ждать при первом запуске.

### 3.3 Шаблон промпта (фотореализм)

```
RAW candid smartphone photo of a {age}-year-old adult {ethnicity} woman, {hair_length} {hair_style} {hair_color} hair,
{eye_color} eyes, {body_type} figure, {outfit}, {pose}, {location}, {lighting},
natural skin texture with pores, subtle makeup, realistic proportions, shot on iPhone, 35mm, shallow depth of field,
photorealistic, high detail
```
negative_prompt (если модель поддерживает):
```
cartoon, anime, 3d render, illustration, painting, cgi, plastic skin, doll, deformed hands, extra fingers,
blurry, watermark, text, logo, child, teen, nudity
```

Параметры: `model: "default"`, `image_size: "portrait_4_3"` (карточки) или `"portrait_16_9"` (полноэкранные фото), `output_format: "jpeg"`, `enable_safety_checker: true`. `seed` первого удачного портрета сохраняется в профиль персонажа.

### 3.4 Консистентность лица
- У каждого персонажа есть **reference-портрет** (лицо анфас, нейтральный фон) — хранится локально.
- Все последующие фото персонажа (галерея, фото в чате, генерация сцен) делаются через `POST /media/image2image` с `image_urls: [reference]` (base64 data URI локального файла) и промптом «the same woman from the reference photo, {новая сцена/одежда/поза}».
- Для лучшей похожести допускается модель `quality` (принимает несколько изображений): `[reference, лучшая предыдущая фото]`.

## 4. Интеграция с API (LLMApps)

### 4.1 Общее
- Base URL: `https://llmapps.space`.
- Авторизация: TOTP. Ключ `llm_totp_{prefix}_{secret}` хранится в приложении **в зашифрованном/обфусцированном виде** (не строкой в коде; XOR/AES с ключом, собираемым в рантайме). Токен генерируется каждую минуту: HMAC-SHA256(secret, bigEndian(UInt64(unixtime/60))), base64url → заголовок `Authorization: Bearer llm_totp_{prefix}_{code}` (готовый пример — `examples/swift/LLMAppsExample.swift`, CryptoKit).
- Регистрация приложения у владельца API с типами: `text2text`, `image2text`, `speech2text`, `text2speech`, `text2image`, `image2image`, `image2video`.
- Сетевой слой: `URLSession` + async/await, `Codable`-модели, единый `LLMAppsClient` (actor).
- Таймауты: чат 60 с, медиа (sync) 120 с, медиа async — поллинг до 15 мин.
- Ссылки на результаты (fal.media) **временные**: каждое полученное фото/аудио/видео сразу скачивается и хранится локально.

### 4.2 Обработка ошибок
- Чат: не-200 статус = ошибка.
- Медиа: ошибки провайдера приходят с **HTTP 200** и полем `error` — проверять тело всегда.
- Async submit: `429 too_many_pending` (лимит 3 одновременные генерации на клиента) → ставить задачу в локальную очередь и повторить позже; `402 spending_limit_exceeded` → показать «Сервис временно недоступен»; `500` → retry с backoff (1, 2, 4 с, максимум 3 попытки).
- Поллинг `GET /media/status/{id}`: `queued` — раз в 3–5 с, `in_progress` — раз в 2–3 с, стоп на `completed`/`failed`.
- Пользователю — человечные сообщения в стиле персонажа (например «Ой, связь пропала… напиши ещё раз?») + кнопка «Повторить» у неотправленного сообщения.
- В приложении один клиентский семафор на 3 одновременные медиа-генерации.

### 4.3 Карта функций → эндпоинты

| Функция | Эндпоинт | Параметры |
|---|---|---|
| Ответ персонажа в чате | `POST /v1/chat/completions` | `messages`, `max_tokens: 400`, `response_format: json_schema` (см. 4.4). Поле `model` не передаётся |
| Пользователь прислал фото | `POST /v1/chat/completions` | часть `image_url` с base64 data URI (image2text) |
| Голосовое пользователя → текст | `POST /media/speech2text` | `audio_data` (base64, m4a/AAC), `content_type: "audio/m4a"`, без `language` (автоопределение) |
| Озвучка ответа персонажа | `POST /media/text2speech` | `text` ≤ 500 символов, `voice_id` персонажа, `voice_speed`, `model: "default"` |
| Создание нового персонажа (портреты) | `POST /media/text2image` | `num_images: 4`, промпт по шаблону 3.3 |
| Фото персонажа в чате / галерее / «Сгенерировать фото» | `POST /media/image2image/async` | `image_urls: [reference]`, промпт сцены → поллинг |
| Короткое видео персонажа (Premium) | `POST /media/image2video/async` | `image_url` — фото персонажа, `duration: 6`, `generate_audio: false` → поллинг |
| Память о пользователе | `POST /v1/chat/completions` | `response_format: json_object`, извлечение фактов (см. 4.5) |

### 4.4 Генерация ответа персонажа

Сборка `messages`:
1. `system` — системный промпт персонажа (шаблон ниже) + блок «Что ты знаешь о собеседнике» (факты памяти) + активный сценарий (если выбран).
2. Последние 30 сообщений переписки (`user`/`assistant`), голосовые — их транскрипт, фото — описание-плейсхолдер.
3. Новое сообщение пользователя.

Системный промпт (шаблон):
```
You are {name}, a {age}-year-old woman from {city}. You are a real person chatting with the user in a messenger, never say you are an AI.
Personality: {traits}. Interests: {hobbies}. Relationship with user: {relationship}. Speaking style: {style}.
Write like in a real chat: short messages (1–3 sentences), emotions, sometimes emoji, ask questions, remember details.
Reply in the user's language. Stay flirty and warm but never explicit. Never describe minors. If the user is in crisis, be supportive and suggest professional help.
When it fits naturally (or the user asks), you may send a photo of yourself.
```

Формат ответа (`json_schema`):
```json
{
  "reply": "текст сообщения",
  "send_photo": false,
  "photo_prompt": "описание сцены/одежды/позы на английском, если send_photo=true",
  "mood": "happy | flirty | sad | playful | caring"
}
```
- Если `send_photo == true` → в чат сразу добавляется текст, затем «фото загружается» (шиммер-плейсхолдер) и запускается image2image. Free-пользователю фото приходит **размытым с замком** (разблокировка за валюту или Premium).
- Если JSON не распарсился — использовать сырой `content` как текст.
- Ответ приходит целиком (стриминга в API нет): показывать typing-индикатор, затем ответ; длинный ответ можно разбивать на 2–3 пузыря с задержкой 0.6–1.2 с для живости.

### 4.5 Память
- Каждые 10 сообщений пользователя фоновый запрос (`json_object`): «Извлеки новые устойчивые факты о пользователе (имя, возраст, город, работа, интересы, важные события, предпочтения)» → массив строк, мержится в `MemoryFact` персонажа (до 50 фактов, дубли отбрасываются).
- Факты показываются в профиле персонажа в разделе «Что она о тебе знает» с возможностью удалить.

### 5.5 Чат (P0 — ядро)
- Хедер: аватар, имя, статус «печатает…» во время ожидания ответа, меню (профиль, сценарий, очистить чат, исчезающие сообщения, удалить диалог).
- Первый вход — приветственное сообщение персонажа (из профиля, без запроса к API).
- Лента: группировка по дням, время у сообщения, статус отправки, свайп для просмотра времени.
- Типы сообщений: текст, голосовое (пользователя и персонажа), фото (пользователя и персонажа), видео персонажа, системные (начало сценария, достижение).
- **Голосовые пользователя**: hold-to-record на микрофоне (свайп влево — отмена), до 60 с, AAC m4a → `speech2text` → транскрипт отправляется в чат как текст пользователя; в пузыре — waveform, play и разворачиваемый транскрипт.
- **Голосовые ответы персонажа** (Premium): кнопка «🔊» на каждом сообщении персонажа + настройка «Отвечать голосом» → `text2speech` (текст > 500 символов обрезается по предложению). Аудио кэшируется. Free — кнопка видна с замком → paywall.
- **Фото пользователя**: из галереи/камеры, сжатие до 1024 px JPEG → image2text, персонаж реагирует на фото.
- **Фото от персонажа**: по `send_photo` (см. 4.4) или по быстрому действию «Попросить фото» (меню над полем ввода). Прогресс — шиммер-плейсхолдер в пузыре.
- Быстрые подсказки (suggestion chips) над полем ввода в пустом/новом чате: «Расскажи о себе», «Как прошёл твой день?», «Пришли фото».
- Долгий тап по сообщению: копировать, озвучить, удалить, сгенерировать ответ заново (для последнего сообщения персонажа).
- Счётчик лимита для free: «Осталось 7 сообщений сегодня» над полем ввода; при 0 — блок с CTA «Получить Premium» и «+5 сообщений за рекламу».
- Ошибка отправки: красный значок у сообщения, тап — повторить.

### 5.6 Chats — список диалогов (P0)
- Ячейка: аватар, имя, последнее сообщение (или «🎤 Голосовое», «📷 Фото»), время, бейдж непрочитанного (у новых фото).
- Свайп: закрепить, удалить.
- Пустое состояние: иллюстрация + «Начни общение» → Explore.

### 5.7 Создание персонажа (P0 базово, полный — Premium)
Пошаговый мастер в стиле candy.ai, на каждом шаге — визуальные карточки-превью (заранее сгенерированные фото-примеры в бандле), прогресс-бар сверху, «Далее» — `PrimaryButton`.

1. Пол: женщина / мужчина / небинарный (по Notion; по умолчанию женщина).
2. Этничность: европейская, латина, азиатская, арабская, африканская, смешанная.
3. Возраст: 21–25 / 26–30 / 31–40 / 40+.
4. Глаза: карие, голубые, зелёные, серые.
5. Волосы: длина и причёска (прямые, волнистые, кудрявые, каре, хвост, чёлка) + цвет (брюнетка, блондинка, рыжая, чёрные, розовые).
6. Телосложение: стройное, спортивное, среднее, пышное.
7. Характер: выбор из списка (заботливая, игривая, застенчивая, уверенная, остроумная, загадочная, авантюрная, интеллектуальная) **или** ползунки: Нежность ↔ Дерзость, Застенчивость ↔ Открытость, Серьёзность ↔ Юмор.
8. Отношения: подруга, девушка, коллега, соседка, незнакомка.
9. Интересы (мультивыбор, до 5): путешествия, йога, игры, кино, кулинария, музыка, мода, книги, фитнес, искусство.
10. Голос: 4–6 вариантов с кнопкой прослушивания примера (Premium — все, free — 1).
11. Имя (+ кнопка «Случайное»).
12. **Генерация**: `text2image`, `num_images: 4` → экран выбора одного из 4 портретов (кнопка «Ещё варианты» — повторная генерация за валюту). Выбранный → reference-портрет. Затем фоном image2image генерирует обложку и 3 стартовых фото галереи.
13. Готово → профиль персонажа → «Написать».

Альтернатива (P1): загрузка своего фото как аватара (по Notion) — только аватар, не reference для генерации; при загрузке — подтверждение «у меня есть права на это изображение».

Ограничения: free — недоступно (по Notion: либо только имя и аватар из ограниченного набора; решение — free видит мастер, но на шаге генерации — paywall); Premium — без ограничений по количеству.

### 5.8 Генерация фото персонажа (P1)
- Экран из профиля персонажа: выбор пресетов (Одежда: casual, вечернее платье, спорт, пижама, деловой; Место: кафе, пляж, квартира, улица ночью, спортзал; Поза/ракурс: селфи, в полный рост, портрет) + опциональное текстовое уточнение.
- image2image с reference → результат сохраняется в галерею персонажа и Gallery.
- Стоимость в валюте; Premium — N бесплатных генераций в день.

### 5.9 Видео персонажа (P1, Premium)
- Короткое видео 6 с из фото персонажа (image2video, prompt «natural subtle movement, smiles, looks at camera, hair moves in the wind»), используется в галерее и как «видео-сообщение» в чате.
- Видео пресет-персонажей — заранее в бандле/CDN.

### 5.10 Gallery — коллекция (P1)
- Все фото/видео, полученные во всех чатах и сгенерированные, фильтр по персонажу.
- Полноэкранный просмотр, сохранение в Фото (запрос разрешения на добавление), шеринг.

### 5.11 Ролевые сценарии (P1)
- Список карточек сценариев с обложкой: «Свидание в кафе», «Вечер у камина», «Встреча с бывшей», «Попутчики в поезде», «Отпуск на море», «Первый день в новом офисе».
- Сценарий = дополнительный блок системного промпта (сеттинг, роль пользователя, первая реплика персонажа).
- Запуск из меню чата или профиля персонажа; часть сценариев — Premium (замок).

### 5.12 Ежедневные бонусы и достижения (P1)
- Ежедневная награда за вход (серия 7 дней, валюта растёт), экран-модалка с анимацией.
- Достижения: «Первое сообщение», «100 сообщений», «7 дней подряд», «Первое фото», «Создал персонажа» и т.д. → валюта.
- «Уровень близости» с персонажем (растёт от количества сообщений), на уровнях открываются «факты о ней» и фото галереи.

### 5.13 Профиль и настройки (P0)
- Имя пользователя (как обращаться), статус Premium / кнопка покупки, баланс валюты.
- Приватность: блокировка приложения Face ID / Touch ID / код; скрытие превью в App Switcher (blur при неактивности); исчезающие сообщения (по умолчанию выкл., 24 ч / 7 дней) — глобально и на чат.
- История: экспорт переписки (текстовый файл через Share Sheet), удаление истории отдельного чата, «Удалить все данные».
- Голос по умолчанию: автоозвучка ответов вкл/выкл.
- Язык интерфейса: EN (базовый), RU.
- Восстановить покупки, Terms of Use, Privacy Policy, поддержка (email), версия.

### 5.14 Голосовые звонки (P2)
Псевдо-звонок: полноэкранный экран с фото персонажа и анимированной волной; цикл «запись речи (VAD) → speech2text → chat → text2speech → проигрывание». Только Premium.

## 6. Монетизация

### 6.1 Free
| Функция | Ограничение |
|---|---|
| Сообщения | 20 в день (сброс в 00:00 локального времени) |
| Персонажи | 1 предустановленный (выбирается на онбординге/первый в списке), остальные — замок |
| Создание персонажа | недоступно (мастер виден до шага генерации → paywall) |
| Голос | отправка голосовых — да; голосовые ответы — нет |
| Галерея | 1–2 демо-фото на персонажа; фото в чате приходят размытыми |
| Реклама | rewarded video «+5 сообщений» (до 3 раз в день); без баннеров в чате |

Счётчики лимитов хранятся в Keychain (переживают переустановку).

### 6.2 Premium (подписка)
- Безлимитные сообщения.
- Быстрые ответы (без искусственной задержки, которая у free 1–2 с; `max_tokens` выше).
- Все персонажи открыты.
- Неограниченное создание персонажей, выбор голоса и скорости речи.
- Полный доступ к галерее и видео, фото в чате без блюра.
- Голосовые ответы персонажа.
- Эксклюзивные сценарии.
- Без рекламы.
- Ежемесячный пакет валюты для генераций.

Планы: недельный (с trial 3 дня), месячный, годовой (бейдж «Выгодно, -70%» как у candy.ai). Цены задаются в App Store Connect.

### 6.3 Внутренняя валюта ("Gems")
- Начисляются: старт 20, ежедневный бонус, достижения, Premium-пакет, покупка паков (consumable IAP).
- Тратятся: разблокировка фото галереи / фото в чате, доп. генерация фото, повторная генерация портретов при создании.

### 6.4 Paywall
- Фон — фото девушки на весь экран с затемнением, сверху `gradient.premium`-заголовок «Lovira Premium».
- Список оферов (из Notion, с иконками): Unlimited messages · Faster response time · All characters & personalities unlocked · Full photo & video galleries · Advanced voice customization · Exclusive roleplay scenarios · Ad-free experience.
- Выбор плана (карточки, выбранная — розовая обводка), `PrimaryButton` «Продолжить», Restore, Terms, Privacy, крестик через 3 с.
- Точки показа: онбординг, лимит сообщений, замок персонажа/фото/голоса/сценария, кнопка Premium на главной.
- Реализация: StoreKit 2 / Apphud через PremiumKit (в проекте доступен skill `premiumkit-integration`).

## 7. Данные и хранение

Собственного бэкенда нет — всё хранится **локально на устройстве** (SwiftData), медиа — файлы в Application Support.

Основные сущности:
- `Character`: id, isPreset, isPremium, name, age, gender, city, bio, traits[], hobbies[], relationship, appearance (этничность, глаза, волосы, тело), voiceId, voiceSpeed, systemPrompt, greeting, referenceImagePath, coverImagePath, avatarImagePath, seed, intimacyLevel, createdAt.
- `GalleryItem`: id, characterId, type (photo/video), localPath, isUnlocked, unlockPrice, source (preset/chat/generated), createdAt.
- `Conversation`: id, characterId, scenarioId?, isPinned, disappearingInterval?, lastMessageAt.
- `Message`: id, conversationId, role (user/assistant/system), kind (text/voice/photo/video/system), text, transcript?, mediaPath?, audioPath?, status (sending/sent/failed/generating), isLocked, createdAt, expiresAt?.
- `MemoryFact`: id, characterId, text, createdAt.
- `Scenario`: id, title, cover, promptBlock, firstMessage, isPremium.
- `UserProfile`: displayName, intent, gems, streak, lastBonusDate, achievements[], settings.

Приватность и безопасность:
- Data Protection `completeUnlessOpen` для БД и медиа; шифрование хранилища средствами iOS.
- В API отправляется только контекст текущего запроса; аналитика — без текста переписки.
- Исчезающие сообщения удаляются фоновой задачей и при каждом запуске.
- Privacy Manifest (`PrivacyInfo.xcprivacy`), описания `NSMicrophoneUsageDescription`, `NSPhotoLibraryUsageDescription`, `NSPhotoLibraryAddUsageDescription`, `NSCameraUsageDescription`, `NSFaceIDUsageDescription`.

## 8. Нефункциональные требования

- Стек: Swift, SwiftUI, Swift Concurrency, SwiftData, AVFoundation (запись/воспроизведение), CryptoKit (TOTP), StoreKit 2/Apphud, LocalAuthentication. Сторонние зависимости — минимум (кэш изображений допускается свой).
- Архитектура: MVVM + сервисы (`LLMAppsClient`, `ChatService`, `MediaService`, `VoiceService`, `MemoryService`, `EntitlementService`, `Storage`), DI через Environment.
- Устройства: iPhone (портрет) — основная цель; iPad — тот же интерфейс в адаптивной раскладке.
- Производительность: холодный старт < 1.5 с; прокрутка чата и сетки 60/120 fps; изображения — даунсэмплинг и кэш.
- Ответ в чате: typing-индикатор появляется < 300 мс после отправки.
- Офлайн: история и галерея доступны без сети; отправка — с понятной ошибкой и повтором.
- Доступность: VoiceOver-лейблы на кнопках, Dynamic Type для сообщений, контраст текста ≥ 4.5:1.
- Локализация: EN (базовый), RU; String Catalog.
- App Store: рейтинг 18+ (17+ в старой шкале), отсутствие откровенного контента, модерация генераций (safety checker), Age gate, ссылки на Terms/Privacy, кнопка удаления данных.
- Безопасность ключа API: TOTP-ключ обфусцирован, не логируется; в release-сборке нет отладочных логов запросов.

## 11. Критерии приёмки

1. Приложение полностью в тёмной теме, цвета и шрифт соответствуют разделу 2; все основные CTA — розовый градиент.
2. После онбординга и age gate пользователь видит главную минимум с 8 фотореалистичными персонажами.
3. Переписка: персонаж отвечает по-человечески, в своём характере, на языке пользователя, помнит факты из начала разговора (проверка: назвать имя → через 20 сообщений спросить «как меня зовут?»).
4. Голосовое пользователя распознаётся и получает ответ; Premium-пользователь слышит ответ голосом выбранного тембра.
5. Персонаж присылает фото в чате, на котором тот же человек, что и на аватаре (визуальная проверка на 5 фото подряд).
6. Созданный пользователем персонаж: 4 варианта портрета, выбранный становится аватаром, генерации дальше консистентны.
7. Free-лимит 20 сообщений/день работает и сбрасывается; замки ведут на paywall; покупка/restore снимает все ограничения.
8. Ошибки API (включая `error` при HTTP 200 и 429) не роняют приложение и показываются понятно с возможностью повтора.
9. История и медиа доступны офлайн; Face ID-блокировка, исчезающие сообщения, экспорт и удаление данных работают.
10. Сборка без предупреждений о приватности, все usage descriptions на месте, TOTP-ключ не хранится открытой строкой.
